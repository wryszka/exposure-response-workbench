## How footprints are drawn
Lakeview's `symbol-map` plots points, not polygons. Each footprint segment is filled with a regular grid of points
(bounding box × 24, kept where `ST_Contains`), so the area reads as a solid shape. Events with many segments are thinned
(14 or 8 per side — the live MeteoAlarm storm has 72 regions). Layers are one categorical colour field with literal-hex
mappings (light peril colour for the footprint, red = home in the path, slate = clear); marker size is a `marker` column
(footprint 1, clear 2, in path 6) so homes in the path stand out from the back of a room. Rows are ordered by marker so the
in-path homes draw on top.
